# PrismDock

A glass-style Windows workspace for organising Roblox accounts and signing in to the account you select.

Created by [Korambit](https://github.com/Korambit).

## Downloads

The first public Windows preview is being prepared. There is no public installer in this repository yet.

Once published, installers and version notes will be available on the [Releases page](https://github.com/Korambit/PrismDock-Releases/releases). Download the **PrismDock-Setup** EXE attached to the release. GitHub's automatically generated “Source code” archives contain this downloads repository's documentation, not the application or its installer.

## What it offers

- Local Account Packs, with password protection and optional recovery setup.
- CSV, TXT, TSV and JSON account import/export, with previews and custom text formats.
- A separate floating Roblox login window, isolated sessions between selected accounts, and keyboard navigation.
- Manual account categories, activity statistics, sorting, undo and a recycle bin.
- Customisable glass themes, saved layouts and optional soft audio.
- Optional encrypted backups, local history and a sanitised support report.

PrismDock helps with manual selected-account sign-in. It does not submit passwords, determine login results or automatically check credentials in bulk. It is an independent project and is not affiliated with Roblox.

## Local data

No PrismDock account is required. Account Packs and settings stay on your computer; creating a GitHub account is not required to download public releases. Account exports contain plaintext credentials: keep them private.

The configured public build will check release metadata on GitHub for updates. Selected public Roblox profile information and Roblox sign-in use Roblox services. Credentials and Account Packs are not uploaded to this repository.

## Feedback

Use [Issues](https://github.com/Korambit/PrismDock-Releases/issues) for bugs and feature ideas. Include the PrismDock version and steps to reproduce. A sanitised support report can help, but review it and any screenshots before sharing. Never post Account Packs, passwords, cookies, backup codes, authenticator QR codes or account lists.

Windows preview. The current installer is unsigned; verified Windows publisher identity has not been configured. Linux support is deferred. Source code is privately maintained; this public repository hosts downloads, documentation and feedback.
